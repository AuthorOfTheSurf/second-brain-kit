> [!summary] A map of sections, then every page in the wiki, one line each.

## Sections
Read this map first. Then search this file and `wiki/` for your topic. One line per page below; the detail lives in each page's summary. Add a line here when you add a folder.

- **Concepts** — `wiki/concepts/` — ideas that apply in many situations: a sales method, a training principle, a way of deciding. One concept collects many cases.
- **Cases** — `wiki/cases/` — one real situation: a deal, a launch, a hard conversation, a decision. Links the concepts it tests. Never paste a case into a concept page; link it.
- **People** — `wiki/people/` — people in your life: clients, partners, friends. Only what you've said. Mark gaps "to confirm".
- **Projects** — `wiki/projects/` — live work. Who's involved, the problem as they stated it, the plan, next steps, open threads.
- **Sources** — `wiki/sources/` — books, authors, podcasts, courses. Say whether it was read in full or known from a summary. The original file goes in `raw/`.
- **Mastermind** — `wiki/mastermind/` — advisors: people who've done what you want to do. Each page captures how they think and talk, their go-to moves, and what they'd push back on, then ends with "How they'd advise you". See [[wiki/concepts/the-mastermind|The Mastermind]].

## Concepts
- [[wiki/concepts/second-brain|Second Brain]] — how this knowledge base works: one brain any agent can use, one loop, plain files you own.
- [[wiki/concepts/the-mastermind|The Mastermind]] — an advisory board of people who've done what you're trying to do, modeled well enough to ask for their advice.
